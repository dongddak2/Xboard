# 만두 회원가입 연락처 — 2026-10-14

프론트엔드: `https://github.com/dongddak2/cybermandu_v1`의 최신 `main`과 함께 적용합니다. 기존 API 요청에 `real_name`, `wechat_id`, `phone_country_code`, `phone_number`, `contact_version`, `consent_terms`, `consent_privacy`가 추가됩니다. 지역별 이메일 도메인과 이메일 인증은 유지합니다. 이전 가입 클라이언트는 새 필수 항목을 지원하도록 업데이트해야 합니다. 기존 회원의 로그인 정보·비밀번호·UUID·토큰은 변경하지 않습니다.

국가번호는 Google libphonenumber의 공개 메타데이터에서 추출한 고정 목록입니다. 전화번호는 연락처 정보이며 휴대폰 인증을 의미하지 않습니다. 한국 등 국가의 국내 접두사 `0`은 국제번호 저장 시 정규화하며, 이탈리아처럼 번호의 일부인 `0`은 유지합니다. `wxid_` ID는 안내 대상이며 가입을 강제로 거부하지 않습니다.

## DB 적용

`database/migrations/2026_10_14_000001_create_v2_user_contact_table.php`가 신규 `v2_user_contact` 테이블 하나를 만듭니다. 기존 사용자 테이블을 수정하거나 과거 사용자 정보를 임의로 채우지 않습니다. 테이블이 없으면 공개 설정의 `signup_contact_policy.available`은 false이고 가입을 중단합니다. 동일 계정 생성 트랜잭션 안에서 연락처와 법적 동의 버전·시각을 저장합니다. 저장 실패는 계정 생성도 취소합니다. 기본 User 직렬화나 로그인 응답에 연락처가 포함되지 않습니다.

운영 DB 변경 승인을 받은 뒤 백업과 현재 스키마 상태 확인 후 이 마이그레이션만 적용합니다. 전체 미적용 마이그레이션을 함께 실행하지 마세요. 코드 롤백 시 새 연락처 테이블을 자동으로 삭제하지 않습니다. 기존 관리자 계정 삭제 기능을 실행하는 경우 해당 계정의 새 연락처도 동일 트랜잭션에서 제거됩니다. SQL로 사용자를 직접 지우는 운영 작업은 연락처 보유 정책을 별도로 확인해야 합니다.

## 이메일 발송과 비밀번호 찾기

SMTP 설정 및 메일 작업자(Horizon/queue worker)가 정상이어야 인증메일을 발송할 수 있습니다. 가입 코드는 지역별 키로 저장하고, `purpose=password_reset` 요청은 비밀번호 찾기가 사용하는 기존 키에 저장합니다. 비밀번호 찾기 코드를 가입 인증으로 재사용할 수 없습니다. 기존 CAPTCHA와 발송 제한은 유지됩니다.

## 검증 범위

PHP 문법, 가입 정보 정규화·거부 사례·국가번호 데이터·SQLite 저장·저장 실패 시 트랜잭션 취소, 기존 이메일 정책 및 등록된 전체 검사 통과. PHP fixture는 실제 서비스 클래스를 실행하지만 Laravel HTTP 런타임과 실제 운영 DB·SMTP는 실행하지 않습니다. 적용 후 공개 설정, 실제 인증메일, 가입 및 비밀번호 찾기를 별도로 확인해야 합니다.
